# 来源与取舍说明

## 原始来源

| 来源 | 在项目中的位置 | 处理方式 |
|---|---|---|
| 离线特征工程原始工作区 | `01_离线数据处理与特征工程`、`04_模型参数` | 复制 MATLAB 源码和小型参数；未包含原始数据及 GB 级中间矩阵 |
| Python 训练原始工作区（S2 model） | `02_Python训练与后处理`、`04_模型参数` | 复制训练/后处理源码和在线需要的小型权重；未包含完整交叉验证结果 |
| MATLAB 在线测试原始工作区（模块规范版） | `03_在线MATLAB测试` | 作为推荐在线基线复制模块化 MATLAB 代码；未包含患者结果目录 |
| 嵌入式 C 原始工程 | `06_嵌入式C部署/epil_src` | 只读复制 38 个 `.c/.h` 源文件；未包含 STM32 HAL/BSP 板级例程和板上脱敏 txt 回放数据 |

## 未复制内容

原始工作区中的 `data`、`alltrain*`、`xunlianji*` 大型 MAT 矩阵、批量预测 CSV/XLSX 和其他历史版本未包含在本仓库中。这些文件体量大且可能包含患者信息，不适合作为项目仓库默认内容。

## 配置原则

当前在线配置已改为相对于项目根目录读取 `04_模型参数`。数据集、折叠信息和真实发作记录仍由使用者在 `online_project_config.m` 中配置。原始工作区完全未修改。
