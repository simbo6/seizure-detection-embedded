# 项目检查清单

## 使用前

- [ ] 在 `03_在线MATLAB测试/1_Main/online_project_config.m` 填写数据目录、折叠信息和真实发作记录路径。
- [ ] 确认 MATLAB 当前版本具备项目所需工具箱和并行计算能力。
- [ ] 确认 `04_模型参数` 中的 fold、特征数量、归一化参数、FCM 参数和 SVM 权重来自同一实验配置。
- [ ] 确认数据已经脱敏，输出文件不会带出不必要的患者身份信息。

## 训练复现

- [ ] 准备 MAT v7.3 样本和对应的五折划分。
- [ ] 安装 `02_Python训练与后处理/requirements.txt` 中的 Python 依赖。
- [ ] 记录特征选择方法、滤波阶数、特征数量、SVM 参数和随机种子。
- [ ] 将训练产生的 `w.npy`、`b.npy`、归一化参数、FCM 参数和特征编号成套归档。

## 在线验证

- [ ] 先用单个脱敏 MAT 文件运行 `run_online_pipeline`。
- [ ] 检查窗口级 points、事件级 events 和 result.mat 是否生成。
- [ ] 再运行批处理并核对事件延迟、漏检和误报指标。
- [ ] 不要直接运行历史 `main_preprocess_feature.m` 处理唯一原始文件；该脚本包含删除输入 MAT 的语句。

## 嵌入式 C 部署

- [ ] 确认 `06_嵌入式C部署/epil_src/EpilAlgo1.c` 里硬编码的 `PS1_mean / PS2_mean / w / b_model / mdl_FCM_2` 与 `04_模型参数/` 当前 fold 一致。
- [ ] 在 PC 端用任意 C99 编译器先单测 `EpilAlgo1` 单元（用一组已知 6 秒窗的输入），再上板。
- [ ] 板上 `test.c` 里的 `acc_data_hmy0919.txt` 等文件名按本机 SD 卡内容修改。
- [ ] 对比 MATLAB 与 C 端的每秒 fit 序列，浮点误差应 < 1e-3。
